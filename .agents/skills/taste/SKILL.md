# Taste Skill (Inspired by Leonxlnx)

## Objective
Eliminate "AI Slop" and generic default patterns. Create high-variance, professional UIs.

## Principles
- **Design Variance**:
  - Break standard 4px/8px grid monotony where appropriate for visual interest.
  - Use custom-tuned easings (e.g., `cubic-bezier(0.16, 1, 0.3, 1)`).
- **Architecture**:
  - Enforce hardware-accelerated CSS.
  - Mandatory `memo()` for complex component sub-trees.
  - Avoid large component files; modularize by feature.
- **Visual Balance**:
  - Information density must feel intentional—neither cluttered nor empty.
  - Use "optical alignment" instead of just mathematical centering.
- **Micro-interactions**:
  - Every interaction should have a "reaction."
  - Use subtle gradients and glassmorphism for depth.
