# Impeccable Skill (Inspired by pbakaus)

## Objective
Production-grade design language and workflow management.

## Workflow: The Three Gates
1. **Teach**: Identify context (PRODUCT.md, DESIGN.md).
2. **Shape**: Create and confirm a design brief.
3. **Craft**: Implement with obsessive attention to detail.

## Mandatory Preflight (IMPECCABLE_PREFLIGHT)
Before any code mutation, you must explicitly state:
- **Product Context**: What are we building and for whom?
- **Design Brief**: What visual rules are we following?
- **Implementation Plan**: Step-by-step technical approach.

## Implementation Standards
- **Typography**: Hierarchy must be crystal clear. Use high-quality fonts.
- **Elevation**: Use consistent shadow systems and z-index management.
- **Cohesion**: Components must feel like they belong to the same family.
- **Edge Cases**: Always handle loading, empty, and error states elegantly.
