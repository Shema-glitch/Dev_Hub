# Dev Hub — The Developer Consciousness Engine

Dev Hub is a high-fidelity productivity platform designed to bridge the gap between your coding activity and your mental context. It acts as a "digital dev-twin," tracking your sessions, raw thoughts, and code changes to ensure you never lose your flow.

## 🚀 Vision
*The best documentation is the one you never had to sit down and write.* Dev Hub automatically synthesizes your engineering intent into a structured, semantic archive.

## ✨ Key Features
- **Neural Synchronization**: Real-time logging of thoughts, bugs, and breakthroughs as you code.
- **Dynamic Island Control**: A central floating synchronization hub for session uptime and deep-focus Pomodoro timers.
- **Intelligence Signals**: AI-generated session briefings and architectural impact mapping.
- **Neural Archive**: A permanent, chronological history of your development journey.
- **Impeccable UI**: A premium, glassmorphic dark-mode interface built for elite focus.

## 🛠 Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4 with custom glassmorphism utilities
- **Components**: shadcn/ui & Phosphor Icons
- **Backend**: Supabase (Auth & Realtime)
- **AI**: Gemini Pro API integration (in development)
- **Animations**: CSS Transitions with custom Expo easings

## 🏁 Getting Started

### Prerequisites
- Node.js 18+
- pnpm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Shema-glitch/Dev_Hub.git
   ```
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Set up your environment variables in `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
4. Run the development server:
   ```bash
   pnpm dev
   ```
